# JARVIS-Brain

A starter Obsidian vault that Claude reads and writes through the Obsidian **Local REST API** plugin's built-in MCP server. Notes stay on Brandon's PC.

- `JARVIS-Brain.zip`: the vault, ready to unzip. Setup steps are in `SETUP.md` inside it (about 15 minutes).
- `out/JARVIS-Brain/`: the same vault, unzipped, for browsing.
- `build.mjs`: regenerates both (`node build.mjs`, then zip `out/JARVIS-Brain`).

Not yet tested on Windows: `scripts/Connect-Claude.ps1` has not been run, and the vault has not been opened in Obsidian.
